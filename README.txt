더누림 홈페이지 정적 시안

1. index.html을 더블클릭하면 브라우저에서 확인할 수 있습니다.
2. css/common.css : 헤더/메뉴/푸터/반응형 공통 스타일
3. css/main.css : 메인 페이지 스타일
4. js/main.js : 모바일 메뉴, 맨 위 버튼, 상담 폼 데모
5. pages/ : 하위 페이지 기본 틀

이미지 교체 권장:
- 메인 배너: .hero의 background를 images/hero.jpg로 변경
- 가족 사진: welcome 영역의 family-art를 images/family.png 이미지로 변경
- 로고: 현재 CSS로 만든 임시 로고이며 실제 로고 파일로 교체 가능

상담 폼은 현재 프론트엔드 데모입니다. 실제 접수에는 백엔드/이메일/DB 연동이 필요합니다.
